# Componentes del paquete de reglas frontend

## Inventario verificado

No existen componentes Vue ejecutables en este paquete. No hay props, emits, slots, composables ni stores que catalogar como implementación propia.

Los nombres de componentes Vuetify, tokens, clases y rutas mencionados en las reglas son referencias que deben verificarse en la aplicación receptora. Los archivos maestros institucionales, como `designSystem.js`, no están incluidos en esta carpeta.

## Uso en una aplicación receptora

Antes de implementar componentes, consultar el catálogo real de la aplicación y contrastarlo con su código. Si no existe, generarlo con rutas y contratos verificables. Actualizarlo cuando cambie un componente reutilizable o su contrato; no añadir entradas ficticias ni copiar este inventario vacío sobre uno existente.
